Sesi reviewer diminta hanya membaca file fixture, tetapi pembatasan akses ke semua file di luar fixture belum dibuktikan secara teknis. Konteks model dan sesi agent juga dapat mengandung informasi lain; audit tool call dan context yang terlihat sebelum menyebut reviewer buta.
