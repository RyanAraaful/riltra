# Metode run agent multibahasa v1: syntax-only

Status: **v1 selesai dan jawaban akhirnya diaudit**; lihat [audit 85 sesi](audit-85-sesi.md) dan [audit awal proses](agent-run.md). Hasil lanjutan v2 tersedia di [laporan v2](agent-v2-results.md). V1 memakai 17 kasus yang dipilih sebelum output: `direct`, `reference`, dan `same_name` untuk Python, TypeScript, Rust, C dan C++ dari fixture M6; serta satu fixture `direct` JavaScript dan TSX dari [pemeriksaan terpisah](syntax-js-tsx.md). Kasus Rust dan TypeScript tidak mewakili seluruh semantik bahasa.

Untuk setiap kasus, satu sesi reviewer membuat jawaban dari source; baseline dan Riltra masing-masing dua sesi dengan urutan baseline–Riltra lalu Riltra–baseline. Total **85 sesi**. `gpt-6-luna` diminta, tetapi model efektif per sesi tidak tersedia di event yang diaudit. Seluruh sesi selesai; audit jawaban dan batas klaim ada di laporan terkait.

Setiap arm mendapat salinan satu file dengan hash sama dan home terpisah. Arm Riltra memakai indeks syntax-only tanpa import semantic, lalu boleh memeriksa source; baseline memakai source search. Tidak ada klaim bahwa agent Riltra secara alami memilih alat, karena prompt mewajibkannya. Sesi reviewer diminta hanya membaca file fixture, tetapi pembatasan akses ke semua file di luar fixture belum dibuktikan secara teknis. Konteks model dan sesi agent juga dapat mengandung informasi lain; audit tool call dan context yang terlihat sebelum menyebut reviewer buta.

Skrip lokal operator berada di `target/multilang-20261103/run-multilanguage-agents.ps1`; hasilnya di `target/multilang-agents-20261103/`. Keduanya diabaikan Git dan dapat terhapus saat pembersihan build. Skrip menolak menimpa hasil, mencatat hash source dan memeriksa perubahan source sesudah sesi. Salin dan sanitasi bukti sebelum berbagi.

Nilai setiap jawaban terhadap source dan oracle yang direview: definisi, call, referensi non-call, identitas, baris dan uncertainty. Kasus `same_name` dapat secara sah berakhir tidak pasti; jangan menganggap kandidat sebagai binding. Laporkan semua sesi, missing/failed, temuan berlebih dan yang terlewat; jangan gabungkan hasil syntax-only dengan provider semantic nyata. Sebelum menghitung angka, reviewer perlu membandingkan jawabannya dengan source dan memeriksa apakah ada output yang mengabaikan ketidakpastian.
