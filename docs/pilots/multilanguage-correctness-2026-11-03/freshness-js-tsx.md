# Freshness dan incremental pada fixture JS/TSX

Pada 3 November 2026, dua file kecil JavaScript dan TSX diindeks di home terisolasi pada Windows. Index cold memproses dua file; database setelah cold berukuran 110.592 byte. Ukuran ini hanya berlaku untuk fixture tersebut, bukan estimasi proyek nyata.

Setelah komentar ditambahkan pada salinan JavaScript, `index status` menyatakan `stale`/`content-changed`. Incremental index menyatakan fresh, memakai ulang satu file dan mem-parsing ulang satu file. Forced full index mem-parsing ulang dua file. Kedua output index melaporkan empat definisi, dua call dan nol syntax error. Hasil `search --symbol target --limit 100` dari incremental dan full sama pada `results` setelah field snapshot dinormalisasi, total dua dan freshness fresh. Ini memeriksa satu query dan satu edit, bukan kesetaraan semua fakta atau seluruh edge graph; tes existing `cli_search_parity_full_vs_incremental` mencakup skenario tambahan.
