# Evaluasi agent v2 — selesai

Pin implementasi `29ee9de75f4712a5142d18a5353f9d747ffcfbbb`. Sebelum output, 17 fixture dan oracle 40 entri dibekukan. Oracle SHA-256 `88847d628660f536e9b8a7b55dc9d4e9d22725b0c3e07a4cbbea4188356d368f`. Agent terpisah diminta membandingkan seluruh oracle dengan source dan melaporkan tidak ada kesalahan. Peninjau melaporkan hanya membuka oracle dan subtree fixture, tetapi akses di luar subtree tidak ditegakkan secara teknis. Kasus dan sebagian acuan sudah dikenal dari v1: review bukan blind dan bukan oracle baru yang bebas kontaminasi.

Run terdiri dari dua sesi baseline dan dua sesi Riltra untuk setiap kasus, total 68 sesi. Salinan source dan home dibuat baru untuk setiap sesi; urutan baseline–Riltra lalu Riltra–baseline. Kedua kondisi menggunakan workspace-write dan home masing-masing; instruksi melarang baseline memanggil Riltra dan mewajibkan kondisi Riltra menggunakannya, tetapi hak teknis tidak membuktikan kepatuhan. Model yang diminta `gpt-6-luna`; sebuah sesi preflight terpisah menampilkan nama itu, sedangkan model efektif seluruh sesi evaluasi tetap perlu diverifikasi dari log yang tersedia.

Percobaan awal memakai sandbox read-only dan dihentikan setelah sesi Riltra melaporkan indeks `db-unreadable`; database tidak dapat dipakai sehingga run itu tidak digabungkan dengan percobaan berikut. Uji terpisah menggunakan workspace-write plus home sendiri berhasil melakukan search pada indeks. Run retry dimulai dari awal dengan home baru; perubahan ini dan seluruh hasil awal dipertahankan. Hash source diperiksa sebelum dan sesudah sesi. Indeks syntax-only, dan agent boleh memeriksa source, sehingga hasil akhir bukan pengukuran terisolasi engine.
